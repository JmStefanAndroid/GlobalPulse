# GlobalPulse v1.0.0 发布说明

GlobalPulse 是全球化多主题消息聚合工具，不是股票软件、行情终端或交易工具。当前版本实现 macOS Intel x64 菜单栏与桌面工作台，**仅在 macOS 13 Intel 上验证**。

## 功能

- 直接接入 15 个真实 RSS 源：BBC 2 个、CNBC 3 个、卫报 2 个、CNA 1 个、NPR 1 个、德国之声 1 个、半岛电视台 1 个、香港电台 2 个、美联储 1 个、联合国中文 1 个。
- 支持预设主题及自定义中英文关键词板块，可新增、删除；当前默认“股票”板块不代表产品仅面向股票。
- 提供菜单栏重点摘要、桌面消息列表、评分依据及来源连接状态。
- 默认按发布时间倒序，未知时间置于最后，可切换为重要性优先；默认筛选规则评分 ≥ 40 分的消息。
- 异步将标题与出版方提供的摘要翻译为中文，显示等待／失败状态，后续刷新重试，并复用未变化内容的缓存译文。
- 本地保留最近 7 天、最多 3000 条消息，抓取失败时保留已有缓存；首次启动不提供假数据。
- 支持 1 / 2 / 5 / 15 分钟刷新、登录启动、已读记录及默认浏览器打开原文；关闭主窗口后仍可后台运行。

## 下载与安装

从 [项目首页的下载安装入口](../../README.md#下载安装) 前往**本仓库 Releases**，选择 `v1.0.0`，下载：

| 文件 | 说明 |
| --- | --- |
| `GlobalPulse-1.0.0-mac-x64.dmg` | Intel x64 磁盘映像安装包 |
| `GlobalPulse-1.0.0-mac-x64.zip` | Intel x64 ZIP 应用包 |
| `SHA256SUMS.txt` | 同版本下载文件的 SHA-256 校验清单 |

1. 对照 `SHA256SUMS.txt` 核验下载文件；校验不一致时不要打开。
2. 打开 DMG，或先解压 ZIP，将 `GlobalPulse.app` 拖入 **Applications（应用程序）**。
3. 从 Applications 启动，等待来源抓取与翻译。

**当前应用未签名、未经 Apple 公证**，macOS 可能阻止启动。仅验证过 macOS 13 Intel，其他系统版本不保证可用；校验和不等于身份认证或安全审查。请遵循系统提示，**勿关闭 Gatekeeper 等系统安全机制，勿通过移除隔离属性等方式绕过检查**；无法通过系统检查时停止安装并反馈。

## 已知限制

- **平台：** 当前仅实现 macOS Intel x64。Apple Silicon、Android、Windows、Linux 及其他平台均未作为可用版本提供。
- **时效：** 属于定时近实时 RSS 聚合，不是交易所实时流或付费通讯社快讯；出版延迟、订阅更新周期、网络封锁和本地时间错误会影响结果，不能保证覆盖所有重要事件。
- **来源：** 配置了 15 个真实源不等于所有源始终在线；各源并发抓取，单源超时 18 秒，连接失败将在后续更新重试。
- **评分与去重：** 启发式评分可能误判、漏判；仅按标准化标题去重，未进行事件级跨源验证，也不是事实核查。工具与评分均不构成投资建议。
- **翻译与隐私：** 标题和摘要会发送至 Google 公共翻译接口 `translate.googleapis.com`，不发送设置、板块或已读记录。接口可能失败、限流，中国大陆可能无法直连；不保证可用性与译文准确性。仅翻译标题与摘要，**不提供全文翻译**。
- **内容版权：** 新闻内容版权归出版方或相应权利人所有，应用不复制全文；原文在浏览器中打开，可能需要订阅。项目 MIT 许可证不涵盖新闻内容权利。
- **本地数据：** 新闻、译文、板块、已读记录与设置保存在本机 `pulse.json`，提交反馈时请勿附带私人数据。
- **分发安全：** 尚未完成 Apple 签名、公证及独立安全审查，不应将当前版本视为已获安全认证。

## 开发

需要 Node.js ≥ 22.12。使用 `npm ci` 安装依赖、`npm test` 运行测试、`npm start` 启动开发应用；`npm run pack` 生成本机 macOS 应用目录，`npm run dist:mac` 生成 Intel x64 的 DMG 与 ZIP 且不自动发布。

输出位于 `release/`，文件名规则为 `${productName}-${version}-${os}-${arch}.${ext}`。这些打包命令不会自动完成签名、公证或生成 `SHA256SUMS.txt`，校验清单需另行准备。翻译测试采用模拟请求；真实来源可通过 `npm run check:feeds` 检查。
