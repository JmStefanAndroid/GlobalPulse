GlobalPulse 面向全球新闻与多主题信息追踪，支持军事、科技、能源、财经等关键词板块，**不是股票软件、行情终端或交易工具**。当前默认板块名为“股票”，仅作为现有主题入口；可添加自定义板块，也可删除全部板块。

> **平台状态：** 当前已实现 macOS Intel x64 版本，**仅在 macOS 13 Intel 上验证**。Apple Silicon、Android、Windows、Linux 及其他平台均为计划中，暂无发布日期，也不代表已有可用版本。

## 功能一览

| 功能 | 当前能力 |
| --- | --- |
| 多主题聚合 | 预设主题与自定义中英文关键词，支持新增、删除板块 |
| 真实新闻来源 | 直接接入 15 个 RSS 源，无需 API 密钥，不注入演示消息 |
| 菜单栏与桌面 | 菜单栏摘要速览，桌面工作台查看消息、评分依据和来源状态 |
| 默认排序 | 按发布时间倒序，未知时间置于最后；可切换为重要性优先 |
| 重点筛选 | 默认显示规则评分 **≥ 40 分** 的消息，“全部消息”查看其他匹配内容 |
| 中文阅读 | 异步翻译标题与出版方提供的摘要，显示翻译状态并复用缓存译文 |
| 本地缓存 | 保留最近 **7 天**、最多 **3000 条**消息；抓取失败时保留已有缓存 |
| 后台刷新 | 支持 1 / 2 / 5 / 15 分钟更新频率、登录启动和已读记录 |
| 原文访问 | 在默认浏览器打开出版方原文，不提供全文翻译 |

## 下载安装

前往**[本仓库 Releases](https://github.com/JmStefanAndroid/GlobalPulse/releases/latest)**，选择 `v1.0.0`，下载 Intel x64 对应文件：

| 文件 | 用途 |
| --- | --- |
| `GlobalPulse-1.0.0-mac-x64.dmg` | 推荐的磁盘映像安装包 |
| `GlobalPulse-1.0.0-mac-x64.zip` | ZIP 格式应用包 |
| `SHA256SUMS.txt` | 对照下载文件的 SHA-256 校验值 |

1. 下载所需安装包与同一版本的 `SHA256SUMS.txt`，核对文件 SHA-256 与清单一致；不一致时不要打开。
2. 打开 DMG，将 `GlobalPulse.app` 拖入 **Applications（应用程序）**；使用 ZIP 时先解压，再将应用拖入 Applications。
3. 从 Applications 启动应用，等待 RSS 抓取及中文翻译完成。

> **安全提示：** 当前应用**未签名、未经过 Apple 公证**，macOS 可能阻止打开；仅验证过 macOS 13 Intel，其他系统版本不保证可用。校验值只能帮助检查文件一致性，不能代替签名、公证或安全审查。请仅从本仓库 Releases 获取文件，遵循系统安全提示；**不要关闭 Gatekeeper 等系统安全机制，也不要通过移除隔离属性等方式绕过检查**。无法通过系统检查时，请停止安装并反馈问题。

详见 [v1.0.0 发布说明](docs/releases/v1.0.0.md)。

## 快速使用

- 点击 macOS 顶部 **◉** 查看重点摘要，点击消息在默认浏览器打开原文。
- 点击“打开完整工作台”，查看摘要、评分依据及来源连接状态。
- 点击板块 `＋` 选择预设，或输入以逗号分隔的自定义中英文关键词；侧栏悬停 `×` 删除板块。
- 默认按发布时间倒序显示 ≥ 40 分消息；可切换排序或进入“全部消息”。未知发布时间单独标记，并置于最后。
- 设置中调整更新频率或开启登录启动。关闭主窗口后仍在后台刷新；菜单栏图标右键 → 退出，或使用 `Cmd+Q` 退出。

## 来源与时效

代码中配置了 **15 个真实 RSS 订阅源**，不依赖单一新闻聚合商；源的实际可达性取决于网络及出版方服务：

| 出版方 | 订阅内容 | 源数量 |
| --- | --- | ---: |
| 英国广播公司（BBC） | 全球、商业 | 2 |
| 美国消费者新闻与商业频道（CNBC） | 财经、市场、经济 | 3 |
| 卫报（The Guardian） | 国际、商业 | 2 |
| 亚洲新闻台（CNA） | 商业 | 1 |
| 美国全国公共广播电台（NPR） | 商业 | 1 |
| 德国之声（DW） | 国际 | 1 |
| 半岛电视台（Al Jazeera） | 国际 | 1 |
| 香港电台（RTHK） | 财经、国际 | 2 |
| 美联储 | 官方发布 | 1 |
| 联合国 | 中文新闻 | 1 |
| **合计** | | **15** |

各源并发抓取，单来源超时 18 秒；状态页显示连接状态与失败提示。首次启动没有假数据，失败时保留最近缓存。

这是**定时近实时聚合**，不是交易所实时流或付费通讯社快讯。出版方发布延迟、RSS 更新周期、网络封锁与本地时间错误均会影响时效，无法保证覆盖每条重要事件。来源原始发布时间与最近拉取时间分开显示，缺失发布时间标记为未知。

## 重要性规则

评分为启发式规则，基础 18 分；6 小时内 +12，6 至 24 小时内 +6；货币政策 +30，宏观与贸易 +24，地缘风险 +26，市场与企业 +20，经济与资产 +22，产业与监管 +20，最高 99 分。

默认阈值为 **40 分**。关键词匹配可能误判或漏判，仅按标准化标题去重，未进行事件级跨源验证。评分**不是事实核查、涨跌预测或投资建议**。

## 隐私、安全与版权

- **本地存储：** 新闻、译文、板块、已读记录及设置保存在 `~/Library/Application Support/GlobalPulse/pulse.json`；开发运行目录名可能为 `global-pulse`。最近 7 天消息最多缓存 3000 条。
- **翻译数据流：** 公共新闻的**标题与摘要会发送至 Google（谷歌）公共翻译接口 `translate.googleapis.com`**，不发送设置、板块或已读记录。该接口无需密钥，但可能失败、限流或不可达，**中国大陆网络可能无法直连**；不保证服务可用性。
- **翻译范围：** 仅翻译标题与出版方提供的摘要，**不是全文翻译**。翻译期间显示等待提示，失败时显示失败提示，并在后续刷新时重试；内容未变时复用本地译文。机器翻译可能出错，未经事实核验。
- **网络访问：** 应用需要连接各 RSS 域名及翻译服务，实际可用性受网络环境影响。
- **应用安全：** 渲染进程启用沙盒、上下文隔离和 CSP，无 Node.js 访问权限；外链仅允许 HTTP(S)。这些措施不等于独立安全审查，当前也未完成 Apple 签名或公证。
- **内容版权：** 新闻标题、摘要、原文及相关内容的版权归各出版方或相应权利人所有，应用不复制全文；外链打开出版方原文，可能需要订阅。MIT 许可证仅适用于本项目代码，不授予新闻内容使用权。
- **使用边界：** 本工具用于信息聚合与阅读，**不构成投资建议**，重要信息请核对原始来源。

## 开发与检查

需要 **Node.js ≥ 22.12** 和 npm。在项目根目录依次执行 `npm ci` 安装锁定依赖、`npm test` 运行测试，再执行 `npm start` 启动开发应用。

| 命令 | 说明 |
| --- | --- |
| `npm ci` | 按 `package-lock.json` 安装依赖 |
| `npm test` | 检查评分、板块匹配、去重、外链限制及翻译成功／失败／缓存复用 |
| `npm start` | 启动 Electron 开发应用 |
| `npm run check:feeds` | 检查真实 RSS 来源连接，需要网络 |
| `npm run pack` | 打包本机 macOS 应用目录，不生成安装包 |
| `npm run dist:mac` | 生成 macOS Intel x64 的 DMG 与 ZIP，不自动发布 |

构建输出位于 `release/`；分发文件命名规则为 `${productName}-${version}-${os}-${arch}.${ext}`。翻译测试使用模拟请求，不访问真实翻译接口。打包命令不会自动完成 Apple 签名、公证或生成 `SHA256SUMS.txt`，发布时需另行准备校验清单。
